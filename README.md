# HAMLET · 王子的复仇 🗡️

一款以莎士比亚《哈姆雷特》为主题的 **五幕横版过关史诗游戏**。前端使用 HTML5 Canvas + 原生 JavaScript，游戏图形由 Canvas 代码绘制，音乐音效由 Web Audio API 程序化合成；联网昵称、留言板与 Boss 击杀排行通过 Supabase JS SDK 接入。

▶️ **在线试玩**：https://raymondliang2026.github.io/HamletGame/

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `←` `→` 或 `A` `D` |
| 跳跃 | `↑` / `W` / `空格` |
| 近战 | `J` / `K` / `L` |
| 远程（拾取【亡魂之弓】后） | `F` / `Z` |
| 终极反击 | 能量集满后按 `J`（Boss 战中） |
| 过场 | `继续` / `回车` 推进，`跳过` 跳过 |

移动端支持屏幕虚拟按键。右上角为得分，左上角为血条/弹药，可用顶部按钮静音。

## 五幕结构（忠于原剧本，难度阶梯递增）

1. **第一幕 · 城堡（鬼魂现身）** —— 父王鬼魂揭示被克劳迪奥毒杀的真相；找到城墙尽头的鬼魂触发区推进剧情，击退守卫、躲避尖刺陷阱。
2. **第二幕 · 宫廷（装疯试探）** —— 装疯周旋，收集散落的三份情报以触发“戏中戏”计划。
3. **第三幕 · 剧院/内室（生死抉择）** —— “To be, or not to be”独白；**拾取【亡魂之弓】解锁远程攻击**；戏中戏揭穿克劳迪奥，误杀帘后波洛涅斯。
4. **第四幕 · 湖畔（奥菲莉亚落水）· 分支关** —— **限时救援**，水面即死，需跳跃平台赶到奥菲莉亚身边。成败将分叉后续剧情与视觉风格。
5. **第五幕 · 墓地/王座厅（最终决战）** —— 墓地（约克里克头骨独白、落石机关）→ 宫廷走廊（盾兵/精英连战、毒池陷阱）→ 王座大厅，与克劳迪奥进行 **三阶段 Boss 决战**，随后进入分支结局与通关评级。

## 第四幕分支（贯穿至结局）

- **救援成功（`opheliaSaved = true`）**：奥菲莉亚保持暗紫/玫红朋克造型随行；第五幕替哈姆雷特挡下雷欧提斯毒剑后受伤倒下，最终以蓝白半透明亡魂助战并与克劳迪奥同归于尽，走向哈姆雷特、奥菲莉亚、克劳迪奥三死的原著悲剧。
- **救援失败**：奥菲莉亚沉入水底并夺走亡魂之弓；第五幕哈姆雷特被雷欧提斯毒剑击中，HUD 显示毒素倒计时与扩散效果，最终带毒与克劳迪奥决战，走向哈姆雷特、克劳迪奥双死的冷色悲剧（“The rest is silence.”）。

## 关键系统

- **镜头拉近**：世界缩放 ZOOM≈1.5，相机同时平滑跟随 X/Y 并 clamp 到关卡边界；背景视差层在屏幕空间绘制。
- **检查点复活**：每关多个检查点，死亡从最近检查点重生；Boss 战失败从 Boss 战前检查点重来。
- **三种敌人 + 精英**：巡逻兵（近战索敌）、弓箭手（远程放风筝）、盾牌兵（正面防御，需绕后或远程破防），墓地骷髅变体，中段精英/小 Boss；均有受击闪白/击退与死亡碎裂淡出粒子。
- **场景互动**：可破坏木箱/棺木（掉落弹药/回血/加分）、移动/升降平台、尖刺/毒池/落石机关、隐藏路径中的宝箱。
- **哈姆雷特造型演进**：黑色现代军装/战服方向逐幕升级（服装细节、磨损、湿发、最终幕手持细剑；成功/失败两种最终形态），全部 Canvas 像素绘制，过场展示全身立绘。
- **三阶段 Boss**：P1 近战+召唤喽啰；P2 狂暴化+毒箭+障碍毒池；P3 背景变红+终极技，玩家可用集满能量的终极反击。
- **剧情过场**：半透明遮罩 + 打字机逐字 + 立绘，中英对照引用原文，可跳过/继续。
- **程序化音频**：每幕风格迥异的循环 BGM、Boss 专属主题、过场短曲与全套音效，均由 AudioContext 合成；提供静音开关，音频在用户手势后解锁。
- **HUD/结算**：实时得分、血条、随从血条、弹药与冷却、Boss 阶段血条、救援倒计时、持续按键提示条；通关统计（用时/击杀/评级 S/A/B/C），成功=金色、失败=暗紫。

## 技术

- 单页面：`index.html`（UI/样式） + `game.js`（游戏引擎，约 3300 行）。
- Supabase JS SDK 通过 CDN 引入，用于玩家昵称、全球留言板和 Boss 击杀计数；网络失败时留言板回退到 localStorage。
- 无构建流程，直接静态托管即可运行；`node --check game.js` 可做语法校验。

## 本地运行

直接用浏览器打开 `index.html` 即可（无需服务器）。
