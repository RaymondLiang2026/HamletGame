# HAMLET · 王子的复仇 🗡️

一款以莎士比亚《哈姆雷特》为主题的 **马里奥式横版跑跳过关小游戏**，纯前端实现（HTML5 Canvas + 原生 JavaScript，无外部游戏引擎），所有角色与场景均由代码绘制（像素/简约风）。

▶️ **在线试玩（GitHub Pages）**：https://raymondliang2026.github.io/HamletGame/

## 玩法

| 操作 | 按键 |
| --- | --- |
| 移动 | `←` `→` 或 `A` `D` |
| 跳跃 | `↑` / `W` / `空格` |
| 攻击 | `J` / `K` / `L` |

移动端支持屏幕虚拟按键。

## 关卡（含彩蛋关）

1. **第一幕 · 艾尔西诺城堡** —— 鬼魂的召唤，击退守卫，抵达终点旗帜。
2. **第二幕 · 教堂墓地** —— 掘墓人与苏醒的骷髅。
3. **彩蛋幕 · 柳树湖畔（救奥菲莉亚）** —— 奥菲莉亚坠湖！在 **倒计时** 内击退敌人赶到她身边。救起后，奥菲莉亚成为 **随从**，跟随主角并辅助攻击。
4. **终幕 · 王座大厅** —— 与弑君篡位的叔父 **克劳迪奥（Claudius）** 决战（Boss 战，含毒酒杯投掷与冲锋两阶段）。获救的奥菲莉亚并肩助战。

## 特性

- 角色物理：重力、跑动、跳跃、攻击判定与击退
- AABB 碰撞检测（地形 / 平台 / 攻击）
- 敌人 AI：巡逻 + 索敌追击（守卫 / 骷髅）；骷髅会跳跃
- 血量系统：主角、随从、敌人、Boss 各自血条，受伤无敌帧
- Boss 双阶段行为（投掷 / 冲锋）
- 随从系统：奥菲莉亚自动跟随并助攻
- 彩蛋关倒计时救援机制
- 开始界面、过关 / 通关 / 失败判定、镜头跟随、粒子与震屏特效

## 技术

- 单页面：`index.html`（UI/样式） + `game.js`（游戏引擎）
- 无构建、无依赖，直接静态托管即可运行

## 本地运行

直接用浏览器打开 `index.html`，或起一个静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```
